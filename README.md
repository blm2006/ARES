# ARES — dashboard

Giao diện dashboard ARES (AI camera: đếm người, phát hiện té ngã / bất động / đánh nhau).

Trang này chỉ là giao diện: AI, camera, tài khoản và dữ liệu nằm trên **máy chủ ARES**. Mở trang, nhập địa chỉ https của máy chủ (hoặc dùng link có `?server=https://...`), đăng nhập bằng tài khoản trên máy chủ.

Tạo lại file này: `python -m ares_server build-web --server https://<máy-chủ>`.
