Tải app ARES Viewer

App xem dashboard giám sát AI. Camera và AI chạy trên máy chủ; máy của bạn chỉ để xem cảnh báo, clip và camera trực tiếp.

Cài đặt (Windows)
  1. Bấm Windows ở trên để tải file zip.
  2. Chuột phải file zip → Extract All… (Giải nén tất cả).
  3. Mở thư mục ARES Viewer, bấm đúp ARES Viewer.exe. Nếu Windows hiện "Windows protected your PC": bấm More info → Run anyway (app chưa ký số).
  4. Đăng nhập bằng tài khoản quản trị viên đưa cho bạn.

Máy chủ đổi địa chỉ IP? App tự dò lại trong mạng nội bộ. Không dò được thì app hỏi địa chỉ mới.
